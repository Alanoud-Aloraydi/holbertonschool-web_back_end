# Holberton School Web Back End

This repository contains Python projects focused on back-end development concepts. The exercises introduce static type annotations and build toward asynchronous execution with coroutines, tasks, generators, and comprehensions.

## Projects

| Directory | Main Topics |
| --- | --- |
| `python_variable_annotations` | Function and variable annotations, complex typing, duck typing, and `mypy`. |
| `python_async_function` | `async` and `await`, concurrent coroutines, runtime measurement, and `asyncio.Task`. |
| `python_async_comprehension` | Asynchronous generators, async comprehensions, and parallel execution with `asyncio.gather()`. |

## Code Quality

The Python source files include:

- the required `#!/usr/bin/env python3` interpreter line;
- type annotations for functions and coroutines;
- module and function documentation;
- formatting compatible with `pycodestyle 2.5.x`;
- syntax compatible with the Python version required by each project.

Each project directory contains its own `README.md` with a focused explanation of its concepts and files.
